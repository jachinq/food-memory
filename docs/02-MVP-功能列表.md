# 食忆 MVP 功能列表

## 1. MVP 目标

MVP 目标是用最小功能闭环验证“个人菜品记忆库”是否有效解决用户忘记曾经做过的菜的问题。

MVP 优先完成：记录一道菜、记录一次制作、通过图片/标签/状态找回菜、从历史成功菜中获得复做推荐、PC 与手机端顺畅使用、Docker 部署为 Web 应用。

## 2. 优先级说明

| 优先级 | 说明 |
| --- | --- |
| P0 | MVP 必须完成，否则核心闭环不成立 |
| P1 | 强烈建议完成，明显提升可用性 |
| P2 | 可延期到后续版本 |

## 3. P0 功能

### 3.1 菜品新增

必填字段：菜名、状态。可选字段：封面图、来源链接、来源平台、主要食材、标签、口味、场景、难度、耗时、备注。

验收标准：PC 和手机端均可新增；手机端表单分组清晰；保存后进入详情或返回列表。

### 3.2 菜品列表

卡片展示封面图、菜名、状态、评分、最近制作时间、标签。

验收标准：PC 端支持网格/表格视图；手机端使用卡片流；无图片时显示默认占位图。

### 3.3 菜品详情

展示基础信息、来源链接、标签与食材、当前状态、综合评分、制作次数、最近制作时间、制作记录列表。

验收标准：可以从列表进入详情；可以编辑菜品；可以新增制作记录。

### 3.4 菜品编辑与删除

验收标准：编辑后列表和详情同步更新；删除前二次确认；删除菜品时关联制作记录一并删除或逻辑删除。

### 3.5 制作记录新增

字段：制作日期、成品照片、本次评分、成功状态、本次备注、下次注意。

验收标准：一道菜可以有多条记录；保存后自动更新 last_cooked_at、cook_count、rating。

### 3.6 制作记录列表

在菜品详情中按时间倒序展示历史制作记录，手机端图片可点开查看大图。

### 3.7 搜索

搜索范围：菜名、主要食材、标签、备注。支持“鸡肉”“下饭”“甜辣”等非菜名关键词。

### 3.8 筛选

MVP 必备筛选项：状态、标签、是否做过、是否成功。支持组合筛选和一键清空。

### 3.9 首页

模块：最近做过、想做清单、很久没做但评分高、随机一道旧菜。每个模块最多展示 3 到 6 道菜。

### 3.10 图片上传

支持 jpg、jpeg、png、webp；限制单张图片大小；上传后返回可访问 URL；列表使用缩略图展示。

## 4. P1 功能

| 功能 | 说明 | 验收标准 |
| --- | --- | --- |
| 复做清单 | 标记近期想再做 | 首页展示，可取消标记 |
| 评分推荐 | 根据评分和最近制作时间推荐旧菜 | 评分 >= 4 且 30 天未做优先推荐 |
| 标签快速选择 | 从已有标签选择或新增 | 输入新标签自动创建 |
| 数据统计 | 总菜品数、已做数、成功数、本月制作次数 | 首页展示统计卡片 |
| 移动端快捷新增 | 手机底部“+”按钮 | 不遮挡内容，支持快速新增 |

## 5. P2 功能

- AI 自动识别截图中的菜名、食材、标签
- 来源链接解析
- 定时提醒
- PWA 添加到桌面和离线缓存
- 多用户和家庭共享
- 数据导入导出

## 6. MVP 页面清单

| 页面 | 优先级 | 说明 |
| --- | --- | --- |
| 首页 | P0 | 概览与推荐 |
| 菜品库 | P0 | 列表、搜索、筛选 |
| 菜品详情 | P0 | 菜品信息与制作记录 |
| 新增菜品 | P0 | 创建菜品 |
| 编辑菜品 | P0 | 修改菜品 |
| 记录制作 | P0 | 新增制作记录 |
| 复做清单 | P1 | 管理想再做 |
| 设置 | P2 | 标签、导入导出 |

## 7. MVP 接口清单

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| /api/dishes | GET | 查询菜品列表 |
| /api/dishes | POST | 新增菜品 |
| /api/dishes/:id | GET | 查询菜品详情 |
| /api/dishes/:id | PUT | 修改菜品 |
| /api/dishes/:id | DELETE | 删除菜品 |
| /api/dishes/:id/records | GET | 查询制作记录 |
| /api/dishes/:id/records | POST | 新增制作记录 |
| /api/records/:id | PUT | 修改制作记录 |
| /api/records/:id | DELETE | 删除制作记录 |
| /api/tags | GET | 查询标签 |
| /api/upload | POST | 上传图片 |
| /api/home/summary | GET | 首页汇总 |

## 8. MVP 不做内容

MVP 暂不做公开菜谱社区、复杂账号权限、评论点赞、第三方社交平台深度接入、自动视频解析、复杂 AI 推荐、购物清单、营养分析。

## 9. 版本里程碑

- v0.1 原型版：完成页面原型，使用 Mock 数据展示核心流程。
- v0.2 本地可用版：完成 Golang API、Vue + Vite 前端、本地数据库可运行。
- v0.3 Docker 部署版：完成 Dockerfile、docker-compose、图片持久化目录。
- v1.0 MVP 发布版：完成 P0 功能、响应式适配、基础测试和部署文档。
